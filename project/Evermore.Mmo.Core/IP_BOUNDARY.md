# MMORPG implementation boundary

This repository implements original, engine-neutral MMORPG mechanics. It does not copy proprietary source, content databases, maps, art, audio, UI layouts, server protocols, credentials, authentication flows, or client behavior.

Product and trademark names in source-disposition documentation identify the requested compatibility category only. No affiliation or compatibility guarantee is asserted. Public distribution should receive an independent license and trademark review.

Dynamic client/editor integrations belong behind documented adapters. The Native AOT core uses compile-time-known C# types, source-generated JSON, deterministic transitions, and explicit authority boundaries.
