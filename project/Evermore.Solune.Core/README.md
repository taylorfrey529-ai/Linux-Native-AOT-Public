# Evermore.Solune.Core

Dependency-free `net10.0` / Native AOT-compatible deterministic feasibility engine for the fictional Solune local-sun construct.

The library evaluates explicit fixed-point orbital, barycentric, radiance, apparent-diameter, rotation, tidal-calibration, and Evercycle equations. It verifies history-wide construct continuity and fails closed unless local construct authority and every containment gate clear. Success returns one pure maintenance directive; the core cannot actuate, spawn, write files, call a network service, access Eastern Kingdoms state, or promote canon.

Primary types:

- `SoluneModelState`
- `SoluneOrbitState`
- `SoluneRadianceState`
- `EvercycleState`
- `SoluneInput`
- `SoluneSnapshot`
- `DeterministicSoluneProcessor`
- `SoluneContainmentPolicy`
- `SoluneSnapshotSerializer`

See `SOLUNE_MODEL_CONTRACT.md` for equations, finite bounds, processing order, containment, and the supplied-plate authority boundary.
